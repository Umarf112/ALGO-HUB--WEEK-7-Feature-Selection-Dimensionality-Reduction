# Week 7 - Feature Selection & Dimensionality Reduction

## Project
Feature Explorer — Streamlit application for exploring feature selection and dimensionality reduction.

## Topics Covered
- Filter Methods: Correlation and Mutual Information
- Wrapper Method: RFE
- Embedded Method: LASSO
- PCA
- t-SNE
- UMAP
- Standardization
- Logistic Regression
- Matplotlib visualization

## Dataset
The project uses the built-in Scikit-learn Breast Cancer dataset, so no external CSV download is required.

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
